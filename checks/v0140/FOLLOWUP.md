UI/UX 기준은 **v1**이다. 게임 버전은 계속 `v0.14.0-dev`, 저장 스키마는 `ep01-script-v11`이다. 이번 작업은 승인 시안의 구현 보완이다.

## R01~R07 결과

| 항목 | 상태 | 근거 |
|---|---|---|
| R01 상단 배경 경계 | 해결 | 사무실·펍·CG 면은 화면 끝까지 채운다. 메뉴를 피할 콘텐츠의 안전 위치는 별도 변수로 유지한다. 390×844에서 사무실·펍 상단 좌표 48px → 0px. 회상·메시지·그림만 보기와 화면 크기별 캡처도 확인했다. |
| R02 메시지 대비 | 해결 | 밝은 메시지 면의 헤더·본문·버튼 색을 명시하고 중복 원격 초상을 감췄다. 팀 메시지 계산 대비: 헤더 10.65:1, 행동 6.57:1, 시간 4.85:1. 개인 대화·공지·어두운 잠금 화면의 표시도 확인했다. 한 메시지씩 공개되는 순서는 유지했다. |
| R03 요청과 실행 순서 | 해결 | 내 준비와 P02에서 목표 → 원문 → 서비스 → 실행 순으로 배치하고, 자세한 사용법·설치 확인은 펼침 영역에 뒀다. 복사 버튼과 실패 시 직접 선택·공식 서비스 열기를 유지했다. 390×844·18px에서 내 준비의 요청 시작 y=825→421, 실행 y=1381→734; P02 실행 y=1330→645. |
| R04 시연 노트 | 해결 | S04의 질문과 수정 답변을 대화 면에서 이어 보여주고 결과 면에는 수정 전후 조건을 표시한다. 모바일 결과 탭은 ‘고친 조건’이다. 390×844·18px의 S04 헤더 높이 264→184px. PC 양면과 모바일 페이지 전환을 유지하고, 낮거나 좁은 화면은 스크롤한다. |
| R05 감상·선택 최소 UI | 해결 | 메뉴로 도구를 모으고 자동 진행 중 정지 행동을 표시한다. 질문과 응답을 같은 선택 영역으로 옮겼다. 800×450에서도 질문을 볼 수 있으며, 보기 모드·키보드 복귀를 확인했다. 대사 음영은 기존 원화 위에 이어진다. |
| R06 실습 복귀 | 해결 | 복귀 질문·자기보고·상담 이어가기·건너뛰기·설치 도움말을 먼저 보이고 요청은 접어 둔다. 390×844·18px 자기보고 행동 y=1623→306. 외부 열기와 복귀, 자기보고 완료는 서로 다른 상태로 유지한다. |
| R07 복귀 명칭 | 해결 | 닫기 문구를 단순화하고 예시 완료는 타이틀·내 준비·펍·선택 화면 등 출발점에 맞게 표시한다. 보이는 메뉴 이름과 접근성 이름을 ‘메뉴’로 맞추고 설정의 현재 위치를 표시한다. |

## 기능 검수

- `source-check.cjs`: 보호 대사 26개와 관계 선택 9개, 첫 요청·추가 요청·설치 ZIP 해시 PASS.
- `content-state.cjs`, `handoff.cjs`: 상태 전이·소유 화면·서비스 이동 검증 PASS.
- `save-compat.cjs`: 기존 저장 위치 797개와 저장 복원 PASS.
- `tutorial-flow.cjs`, `practice.cjs`, `interaction.cjs`: 시연 재개·설치 안내·복사/열기 실패·복귀·수동 저장·A/B/C 관계 경로 PASS.
- `layout-a11y.cjs`, `chatgpt.cjs`, `ui-v1.cjs`, `followup.cjs`: 화면 크기·큰 글자·설치 이미지·키보드 메뉴와 Escape·직접 복사 실패 복구·메시지 대비·낮은 화면 선택 질문 PASS.
- 44개 고정 UI/UX v1 파일과 매니페스트: `verify-uiux.py` PASS, 추가·변경·누락 없음.
- 기존 `story.js`, `request-data.js`, `cards.js`, 동결 저장 앵커, `tutorial-content.js`, `ai-handoff.js` 해시 일치. `practice-ui.js`와 `game.js`는 각각 상태별 표현, 포커스·안전 영역 및 키보드 연결을 위해 변경했다. 요청 데이터, 저장 형식과 상태 전이는 변경하지 않았다.

## 미검증과 한계

- 실제 ChatGPT/Claude 계정에서의 설치·활성화·호출·상담 완료: **NOT VERIFIED**. 외부 열기는 성공·실패를 모의하고 실제 상담 결과로 판정하지 않았다.
- Safari, iOS/Android 실기기, 실제 브라우저 200/400% 확대, 화면 낭독기 청취, 신규 사용자 관찰: **NOT VERIFIED**. 24px 및 200% 글자 재배치 검사는 실제 브라우저 확대와 다르다.
- 화면 캡처와 자동 검수는 로컬 Chromium에서 실행했다. 좁은 화면이나 높은 글자 설정에서는 일반 스크롤로 추가 내용을 읽는다.
