## 남은 검증

실제 모바일 기기·Safari, 주소 표시줄/키보드/안전 영역의 실제 변화, 실제 화면 회전, 스크린리더 청취, 브라우저 실제 확대 검증은 남아 있다. 큰 글자 검사는 앱의 글자 설정과 기존 200% 텍스트 검사다.

실제 계정의 설치·활성화·외부 AI 상담과 실제 서비스에서 돌아오는 returned 경로는 이번에 실행하지 않았다. 관련 PASS는 격리 브라우저에서 열기 결과·복귀 상태를 재현한 기능 검사다. 저장 이식·실패 복구와 수동 슬롯 검사는 통과했지만, 실제 기기에서 장기간 유지되거나 브라우저 데이터 정리 후 복원되는 내구성까지 보장하지 않는다. 사용자의 경력·AI 대화를 수집하는 기능은 추가하지 않았다.
