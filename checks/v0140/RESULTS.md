# v0.14.0-dev · UI/UX v1 첫 통합 결과

2026-10-27 · 로컬 Git 워크트리 · 미배포

## 기준과 범위

- UI/UX: 2026-10-27 승인된 `full-ui-redesign/ui-ux-v1/`. 확정본 44개 파일의 검증 결과 변경·추가·누락 없음.
- 이야기: v0.13의 최신 실행 `story.js` 전체를 그대로 사용한다. 프롤로그+1화, C1/C2/C3, 시연 먼저 → 선택형 설치·실습 → 이야기 복귀. 기존 PILOT_SCRIPT·STORY_BIBLE·MAIN_SCRIPT와 사용 카드 원고는 `docs/story/`에 참조용으로 보존했다. 2~6화 플레이 구현을 완료한 것은 아니다.
- 캐릭터: 2026-10-27 시트 v0.2 다섯 장. 서안·이서·나리·윤 팀장·남성 주인공. 원본 PNG와 동일한 파일을 포함하고, 프로필 위치를 CSS viewport로 표시한다. 이미지 재생성·파일 편집은 하지 않았다. 기존 장면 원화는 보존한다.
- 기존 게임 루트는 수정하지 않았다. 새 저장소의 `baseline/v013` 커밋에서 `implementation/v014-ui-v1` 브랜치를 만든 실제 Git 워크트리다. Codex 관리형 첨부 API는 관리형이 아닌 워크트리를 첨부하지 못하므로, 경로를 직접 사용한다.
- 게임 버전 `v0.14.0-dev` / 목표 UI/UX `v1` / 저장 스키마 `ep01-script-v11` / 공개 배포 없음.

입력 해시와 변경하지 않은 파일은 [IMPLEMENTATION_BASELINE.json](../../IMPLEMENTATION_BASELINE.json)에 기록했다. 설계 문서의 승인·미구현 문구를 새 사용자 요청보다 우선하는 명령으로 취급하지 않았다. 확정 시안은 보존하면서 실제 소스에 구현했다.

숨긴 읽기 도구는 메뉴에서 접근할 수 있다. 설치 안내는 타이틀 ‘CareerPilot 받기’, 내 준비 ‘설치 안내’ 및 ‘설치·사용 안내’, 첫 실습의 ‘설치·선택 안내 보기’에서 열린다. 기존 설치 ZIP은 그대로다.

## 남은 작업과 검증 한계

- **시트 전체를 장면용 자산으로 교체한 버전은 아니다.** 프로필과 인물 열람은 적용했다. 표정·포즈별 투명 스프라이트 제작·정렬·장면별 교체는 후속 미술 작업이다. 서안의 네이비 정장을 업무복 확정안으로 쓰지 않았다. 남성 주인공의 새 정면 얼굴은 현재 시트 열람에서만 보이고, 기존 퇴근/게이트/펍 원화의 뒷모습은 그대로다.
- 실제 Safari, iOS/Android 기기, 실제 브라우저 200/400% 확대, 화면 낭독기 청취, 신규 사용자 이해도는 미검증이다. 글자 200% 재배치는 실제 브라우저 확대와 구분한다.
- 실제 AI 계정 설치·활성화·호출은 확인하지 않았다. 자동 검수는 계정 기능을 보장하지 않는다.
- 새 포트 8922는 기존 8921과 저장 영역이 다르다. 이전 저장 호환 검사는 fixture 및 실제 슬롯으로 실행했지만 이전 주소의 기록을 자동 이전하지 않는다.
- 원 v0.13 실행본과 확정 UI/UX v1은 유지하고, 이 워크트리를 로컬 검토용으로 제공한다. 공개 릴리스 완료로 기록하지 않았다.
