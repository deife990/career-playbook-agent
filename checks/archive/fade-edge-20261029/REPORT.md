# 하단 페이딩 경계 수정 — 2026-10-29

대상: 로컬 v0.14.1 워크트리. UI/UX v1.1.1 확정 시안은 수정하지 않음. 게임 버전/원격 배포는 변경하지 않음.

## 원인과 수정

- 기존 게이트 장면은 스크롤 가능한 text-box에 `0 -24px 60px #18212466` 그림자와 짧은 내부 그라디언트를 함께 적용했다. 투명한 상단에도 그림자가 남아 수평 경계가 드러났다.
- 일반 스프라이트 장면과 CG 장면 모두 별도 전체 화면 dialogue-shade 한 겹으로 처리한다. text-box의 그림자와 중복 배경은 제거한다.
- 읽기 영역 56px 위에서 같은 RGB의 알파 0으로 시작해 여러 단계로 완만하게 증가한다. 본문 12px 전에서 .78, 화면 아래에서는 .94로 도달해 글자 대비를 유지한다.
- 기기/메시지 화면, 선택지, 모달, 전환 중, UI 숨김, 지정 말풍선은 기존 페이딩 제외 조건을 유지한다. Opening은 부가 페이딩을 적용하지 않는다.
- v11-ui 두 파일의 캐시 키만 갱신했다. story.js, 저장, 설치·실습·복귀 로직 미수정. 변경 전 세 파일은 before-source/에 보존했다.

## 확인한 범위

실제 브라우저에서 별도 localhost:8925를 사용해 검수 저장과 기존 :8922 저장을 분리했다.

- 1280×720에서 나리의 ‘둘 다 아직 여기야? 오늘 마감 깔끔하던데.’ 장면 전후 비교. 수정 후 그림자 none, text-box 배경 none, 별도 shade 표시. 시작 경계의 수평선이 사라짐을 시각 확인했다.
- 390×844에서도 동일 대사, 가로 넘침 없음, 글자 표시와 페이딩을 확인했다. 임시 viewport는 해제했다.
- 첫 서사 선택에서 dialogue-shade 숨김을 확인해 선택지 전용 배경과 중복되지 않음을 확인했다.
- 펍 CG 대사에서도 동일한 단일 페이딩 적용, text-box 배경/그림자 none을 확인했다.
- JavaScript 구문 검사 통과. 모바일 메시지/반응 말풍선의 전체 회귀 및 실제 단말 검수는 이번에 실행하지 않았다.
