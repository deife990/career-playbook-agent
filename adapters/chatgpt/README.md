# CareerPilot for ChatGPT
Skill-only portable plugin. Install from the supported local/repo marketplace, start a new session,
then say “이직 준비 시작하고 싶어.” No MCP/auth/backend/API key requirement. Core references are
generated and shared across the twelve small entry skills; no runtime Python scripts.
This authoring directory is itself an install source; distribution archives contain a local
marketplace catalog for the extracted plugin root. Native installation still needs observation.
