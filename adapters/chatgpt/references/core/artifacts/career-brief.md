# career-brief output contract
Career Brief

- Current Position
- Original Requirements
- Career Evidence
- Transferable Skills
- Goals
- Constraints
- Unknowns
- Next Action

A useful first draft can have Unknowns. Do not require all fields or rank worth as a person.
Use [template](../../templates/artifacts/career-brief.md). Important statements carry classifications;
include dated sources for external findings, Unknowns and one next action. Never invent evidence.
