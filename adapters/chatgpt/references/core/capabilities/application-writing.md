# Application form assistant and cover letters

Use selected opportunity, actual field wording/type/limit, confirmed career facts, submitted/draft
resume, stories, JD and current company sources. Every answer runs the [assertion audit](resume.md)
and [human voice](human-voice.md) review. Company research proves company facts, not personal motivation.
Never invent why the user admires/uses a product or wants this company. Ask for one real reason;
without it provide supported role-fit facts and an unanswered motivation question separately.

## Field workflow

1. Identify company/opportunity and actual questions. Greenhouse/Lever/Ashby/Workday/etc. are context,
   not assumed field layouts. Pasted question/screenshot is sufficient; no account connection needed.
2. Classify each field and capture numeric/text/dropdown, required/optional, length unit, actual
   maximum, language and consent. If unknown, propose concise copy with limit unverified, not ready.
3. Retrieve evidence and check missing facts before drafting. Behavioral stories may be selected
   from real candidates with rationale; do not ask the user to retell already confirmed stories.
4. Draft only supportable answers, preserving own vs team role and actual numbers. Respect character,
   word or UTF-8 byte limits as the actual field requires; do not silently truncate meaning.
5. Show ready-to-paste copy, evidence/source/story links internally, field limit check, status and
   remaining unknowns. Keep blocked fields separate. User reviews disclosures and submits.
6. Save exact answer plus field_key/type/limit/unit/provenance/user confirmation. Freeze the actual
   submitted answers with the submitted resume record. Never silently reuse another company's answer.

## Question types and sources

| Type | Grounding and boundary |
|---|---|
| Why company / role | User-confirmed genuine motivation + verified company/JD facts + supported fit; no invented passion |
| Tell us about yourself | Real present/past/target positioning; aspiration is clearly future, not held title |
| Years of experience | Actual relevant dates, overlapping periods counted once; exposure not full ownership; unclear duration→ask |
| Skill-specific | Actual use/context/responsibility; missing skill→honest gap or adjacent bridge, never JD keyword claim |
| Work authorization | Exact user-confirmed country/status; sponsorship and eligibility Unknown until supplied; no legal assumption |
| Salary expectation / current compensation | [Compensation stage support](compensation.md); basis/currency/period/user decision before a number |
| Location / relocation | Confirmed location/willingness/timeframe; no invented eligibility or relocation promise |
| Behavioral short answer | Confirmed STAR spine, personal actions/outcome, compact field-specific answer |
| Portfolio / work sample | Existing authorized artifact and verified link or truthful unavailable; no fake URL/project |
| Additional information | Relevant confirmed context or skip if optional; do not fill with generic praise |

Cover letter: genuine confirmed reason + two relevant evidence anchors + contribution hypothesis
explicitly future-looking; follow actual employer requirements. Missing motivation is not permission
to write an invented draft for later confirmation. Unknown field facts remain blocked. Cover letters,
messages and public profile changes remain optional and user-controlled; no automatic send/upload.
