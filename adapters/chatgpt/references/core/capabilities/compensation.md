# Compensation, references and background-check preparation
Capture currency, base, variable, sign-on, equity type/value/vesting/liquidity, benefits, work
location/style, role/title/manager, start date, contingencies, notice period and deadline from
actual user-provided offer terms. Unknown amounts/conditions remain null. Do not request complete
private contracts; use redacted relevant summaries. No invented salaries or default tax rates.
Separate guaranteed cash from conditional bonus and uncertain equity; label any scenario assumptions.
Unvested/private equity is not guaranteed spendable salary. Exchange rates/current salary benchmarks,
tax/net calculations, legal contract/immigration questions need current authoritative sources and
jurisdiction/date assumptions. If inputs or sources are unavailable, show only supplied gross terms and identify what to verify.
Never fill Unknown tax/net with a remembered rate or estimated numeric range, even labeled INFERENCE.
Before a requested net-pay scenario confirm jurisdiction, tax year, pay interval and personal
assumptions and access current authoritative calculation rules. Distinguish the hypothetical
scenario from actual offer terms. Do not convert base into annual/monthly pay if its interval is unknown.
Reference preparation: identify the kind of referrer needed, confirm permission before contact,
provide an evidence-consistent briefing and message draft; do not persist personal contact details.
Background check: compare accurate employer/title/dates/qualifications to resume, correct discrepancies,
prepare permitted records and explain uncertainties. No misrepresentation or unsolicited secret data.
Negotiation: user priorities and factual market/offer support; respectful draft and alternatives.
Never invent competing offers, inflate prior pay or automatically send/accept/decline anything.

## Before an offer: continuous compensation conversation

Support APPLICATION→RECRUITER_SCREEN→MID_PROCESS→PRE_OFFER→FORMAL_OFFER. Expected salary is not an
offer event. Record actual conversations in Application.compensation_conversations: stage/date,
question/currency/basis/period/location, company/candidate range, source IDs, actual disclosed
answer, confirmation and scope changes. Suggested scripts are recommendations, not past statements.
Current pay is optional/private; do not request payslips or disclose it without user direction.

Establish the actual field/call, role scope, urgency, base vs total, currency and pay interval.
Read original requirements and this opportunity's prior disclosures. Distinguish posted/recruiter
range from market reports and personal expectations. Reconfirm current market facts; no remembered
benchmark, invented percentile, guessed number or default percentage uplift.
- Application free text: offer discussing role scope/package. Numeric-only: ask the user-approved
  actual figure and basis/interval. Never insert 0, guessed salary or fabricated history to pass a field.
  Visibly name the stage (예: “지금은 지원서 입력 단계이며 정식 오퍼 협상이 아닙니다”) and that later
  scope/offer discussion stays possible. Directly ask which annual base number the user chooses to
  enter (or their acceptable minimum/target); research helps the decision, but the number is theirs.
- Recruiter screen: offer requesting the employer band first and a user-approved range option;
  explain tradeoffs without claiming the first number determines the offer. Example recommendation:
  “역할 범위와 보상 구성을 먼저 이해하고 싶습니다. 책정된 범위를 알려주실 수 있을까요?”
- Current salary/history: user decides disclosure; offer focusing on expectations. Do not imply a
  legal ban. Country/state/city/date law requires current official verification; otherwise keep
  legal_status UNVERIFIED/UNKNOWN and ask jurisdiction only if legal guidance is requested.
- Mid-process: compare confirmed new scope to prior alignment. An adjustment uses actual approved
  expectations and evidence; explain scope change, never fabricate leverage.
- Pre-offer: confirm base/variable/sign-on/equity/vesting/liquidity, currency/interval/location and
  constraints. Verbal alignment is not binding written terms.
- Formal offer: W09 uses actual offer and prior conversation history with original requirements.

Give primary/backup scripts for the actual stage and one verification question. Unknown ranges
use no-number copy. Urgent calls can use short scripts with research pending. No salary-history
law, tax/option valuation or negotiation-success claim from external skills is accepted unchecked.
