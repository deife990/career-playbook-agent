# Experience mining: manual / file / optional connected sources
## Input and permission
Existing profile/evidence, sanitized resume/notes, or one episode in conversation. Choose manual
by default; file only if supplied. Optional host Mail/Drive only when available and the user
explicitly permits bounded folders/query/date range. Never ask for a new key/account/connector.
Before connected search confirm scope and exclusions; stop when permission is withdrawn.
## Extract, confirm, persist
1. Ask a concrete challenge and the user's own role; separate “I” actions from team results.
2. Extract generalized context, action, non-sensitive scale, verified/confirmed outcome and skills.
3. Clarify responsibility, dates, counterfactual/causality, measurement method and collaborators
   without identities. Missing scale/impact stays null; ask how measured rather than proposing a number.
4. Present a factual extraction for user confirmation, with disagreements/unknowns.
5. Create CareerEvidence IDs + USER FACT/source_ids/user_confirmed/verification. A supplied resume
   is not external verification. No sensitive/raw message copies in state.
6. Route usable evidence to [story bank](story-bank.md), [resume](resume.md) and evidence mapping.
No experience: student/volunteer/personal projects can be accurately identified, never recast as
paid employment. Exaggeration: refuse false ownership/metrics and offer truthful action wording.
Corrected facts supersede earlier drafts; show affected resumes/stories to review, preserve history.
## Stop and fallback
Enough confirmed material for the target criterion→stop mining; do not search the entire mailbox.
Unavailable tools→conversation/file. Accidentally exposed secrets→redact, do not echo or persist.
