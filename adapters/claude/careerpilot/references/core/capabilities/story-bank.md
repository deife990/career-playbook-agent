# Career Evidence → STAR Story Bank
Select confirmed evidence, never fictional situations. Build Situation / Task / Action / Result /
Reflection with user's own contribution and non-sensitive specifics. Preserve evidence_ids.
Ask only missing facts that change credibility. Unmeasured results remain qualitative; no invented
numbers. Team outcomes are explicitly team outcomes; identify user's action without claiming lead.
Prepare 30/60/120-second spoken variants with a common factual spine. 30: situation/action/result;
60: task/stakes/action/result; 120: alternatives/tradeoffs/learning. Time lengths are rehearsal
targets, not a false stopwatch guarantee. Avoid scripted prose that hides actual depth.
Tag competencies (problem-solving, collaboration, conflict, failure, leadership, execution) only
when evidenced. Map stories to target criteria and interview question tree, with honest limits.
User confirms facts before final versions. W07 review adjusts weak structure/one specific missing
detail; W08 actual questions enrich or revise story emphasis, not historical achievements.
Append revisions with date/reason; retain prior factual context and evidence links.
