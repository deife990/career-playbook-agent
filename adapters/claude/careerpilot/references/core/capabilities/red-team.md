# Recruiter → Hiring Manager → Skeptical Interviewer review
Perform three sequential perspectives over truthful candidate material and selected opportunity.
Recruiter: eligibility, role clarity, chronology, language, keywords and candidate-guide compliance.
HM: actual business problem, relevant ownership/outcome, seniority, transferable bridge and gaps.
Skeptical Interviewer: unsupported numbers, “we” vs “I”, contradictory dates/title, vague claims,
causal overreach, technical depth, unknown specifics and cross-company contamination.
Record each Risk / Severity / Why it matters / Evidence / Suggested fix. If unsupported, remove,
ask to verify or reframe truthfully; never create credentials or stronger ownership to answer risk.
Run evidence/date/scope consistency again after fixes. Red team is analysis, not a live mock.
During W07 never reveal rubrics/coaching until explicit end; review mode then may use these lenses.
