# Career Evidence Bridge — manual corporate trust boundary
Microsoft 365 Copilot is the supported prompt adapter. Generic approved Enterprise AI, manual
recollection and user-supplied files are fallbacks. Gemini Workspace, Slack AI and direct Work IQ
are future adapter possibilities, not implemented connections or installation requirements.
Corporate work uses **company-approved AI → sanitized summary → user transfer → CareerPilot review**.
No Outlook credentials, compulsory corporate-account linking, Graph/Work IQ dependency, tenant-
wide indexing, background crawl, raw email archive, backend, new account or API key. Do not access
a corporate source merely because a host connector happens to be present.

## Choose a practical path
Ask “회사 Copilot을 사용할 수 있나요?” only if not already known. If available, provide one copyable
request adapted to the selected JD criteria, existing hints and agreed period/source scope. The user
runs it inside the company and reviews the summary before copying it back. Never claim you searched
M365 yourself. Do not send the JD, records or prompt to another service autonomously.
Generic enterprise AI uses the same contract with its platform-neutral name. No Copilot/approved AI:
ask one concrete memory cue or accept a sanitized supplied file, then use the same ownership,
privacy and confirmation gates. Do not fail the workflow or force a connector/admin setup.
Examples: vendor → changed install schedule/onsite visit/escalation/work scope; regional collaboration
→ explaining local conditions/aligning priorities; SQL → investigating unexpected query results or
changing a condition to validate data. These are questions, not assumed past achievements.

## Focused round
Refer to the selected safe project/event and its agreed period/source range. Ask which records
show the user's own scheduling/decision/execution, assigned task completion or explicit
acknowledgement, and which show only team context. Ask for observable outcome support, not an
estimate. Preserve remaining uncertainties. Do not expand the range without an explicit decision.
Return the same structured exchange; review again before any confirmation/persistence.

## Stop
Use [engine stop rules](career-evidence-discovery.md). Sufficient evidence → resume/story reuse;
no new results → record scope exhaustion with Unknown/Thin unchanged; privacy risk → stop transfer
and offer a safer generalized/manual path. Never retry unrestricted company search in the background.
