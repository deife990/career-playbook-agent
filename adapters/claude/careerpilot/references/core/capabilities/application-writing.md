# Cover letters and application answers
Read selected Candidate Strategy, official instructions/word limits and confirmed evidence.
Cover letter: genuine motivation grounded in sourced company role context + two evidence anchors +
specific contribution thesis; inferred motivation is proposed wording for user confirmation.
Application answers: answer the actual question/limit, map evidence IDs, distinguish team/own
actions and use supported metrics. Unknown visa eligibility/salary expectations/dates require user
input; never invent or promise. Preserve applicant consent and disclosures as human decisions.
Audit cross-document facts, dates and scope. No current company claims from model memory.
Return editable drafts and remaining factual checks. Mark ready only after confirmations and
red-team corrections; “ready” is not “submitted”. Draft recruiter/networking messages separately.
