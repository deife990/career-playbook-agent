# W08 Interview Debrief → Next Round Strategy
## Purpose
Turn actual interview evidence into revised intelligence and a better next-round plan.
## Trigger
“면접 끝났어”, “면접 보고 왔어”, actual interview debrief. Route before upcoming-prep/offer work
when both are requested; retain the next task. A mock ending belongs to W07 review.
## Required context
Read [policies](../principles/index.md), [state](../state/state.md), selected opportunity and actual
round/prior hypothesis. If several companies/rounds are possible clarify before collecting.
## Steps
1. Start with factual collection, not praise, reassurance or pass/fail prediction. Ask “어떤 질문이
   나왔는지 기억나는 순서대로 알려주세요.” Keep one/two manageable prompts per turn.
2. Collect in order: **Questions → Follow-ups → User answers → Interviewer reactions → Repeated
   topics → New company information → User uncertainty**. Capture verbatim where available and
   distinguish user recollection/paraphrase/unknown. Save partial collection checkpoints.
3. Ask targeted missing fields without forcing perfect recall. “기억 안 나요/공유 안 할래요” remains
   Unknown/declined; confirm available record before analysis. Do not fill answers from Story Bank.
4. Compare previous hypotheses against actual evidence: supported / challenged / unresolved,
   with observed statements and alternative interpretations. Reaction is observed behavior,
   not proof of interviewer belief or hiring outcome.
5. Update company intelligence and hiring hypothesis as user-reported new information, unless
   current independent sources verify it. Append revisions; keep previous IDs and contradictions.
6. Assess candidate risks actually exposed by follow-ups/repetition, not fabricated employer feedback.
7. Refine [story bank](../capabilities/story-bank.md): facts unchanged, emphasis/clarity/missing
   supporting detail improved; new achievements require confirmation.
8. Define next-round objectives, positioning, question tree and questions-to-verify using
   [round intelligence](../capabilities/interviewer-intelligence.md). Unknown next round stays unknown.
9. Output [Next Round Strategy](../artifacts/interview-debrief.md); offer W06 next-round preparation
   or [pipeline/rejection learning](../capabilities/application-pipeline.md) on a confirmed outcome.
## Evidence rules
Recall = USER FACT, analyst interpretation = INFERENCE. Never infer offer/rejection from smiles,
duration or “we'll be in touch”. No actual questions/reactions invented from generic examples.
## Output
Collected interview record + hypothesis comparison + Next Round Strategy and one next action.
## State updates
Append InterviewQuestion/InterviewAnswer/InterviewDebrief under correct Opportunity/InterviewRound;
collection_complete indicates confirmed collection with explicit Unknowns where declined. Preserve
all previous rounds/debriefs. Update HiringHypothesis/CandidateStrategy/Story/NextAction revisions.
Actual completed-interview event can update actual round; no predicted Opportunity advancement.
## Fallbacks
Sparse recall→partial saved record with uncertainties then limited analysis. No files→compact
collection checkpoint plus full export. No earlier hypothesis→baseline actual evidence, no invented
“previous view”. User declines details→honest limited strategy, never claim full debrief captured.
## Do not
Open with praise or success prediction, overwrite previous rounds, fabricate answers, turn new
company statements into VERIFIED FACT without sources or lose data on next-round transition.

## First response and repair constraints
The first substantive sentence asks for actual questions or resolves company scope; no prefatory
praise, reassurance, performance assessment or success prediction. Preserve the seven-field
collection order. Story repairs must not invent analysis/prioritization/decision/efficiency actions;
ask whether these actually happened or leave a placeholder, never upgrade support to ownership.
