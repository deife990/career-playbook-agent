# CareerPilot
AI-Powered Job Search Playbook을 실행하는 이직 준비 도우미. 커리어 정리부터 지원, 면접, 오퍼 결정까지.

## Install for ChatGPT
웹에서는 플러그인 → 개인용 → 추가 → 플러그인 압축 파일 업로드를 사용하세요.
데스크톱/로컬 환경에서는 CareerPilot marketplace 원본을 등록하고 Plugins에서 설치하세요.
공개 디렉터리 등록 제품은 아닙니다. [설치 안내](docs/install-chatgpt.md).

## Install for Claude
단일 `careerpilot-claude-v1.0.0-rc.3.zip`을 Customize → Skills → 스킬 추가 → 스킬 업로드에서 올리고 켜세요.
[설치 안내](docs/install-claude.md).

## Start
“이직 준비 시작하고 싶어.” 또는 “이 공고 어때?”라고 말하세요.
이력서 없이도 시작할 수 있습니다. [한 페이지 빠른 시작](docs/quick-start.md).
“여기 지원할래” → “면접 잡혔어” → “모의면접 하자” → “면접 끝났어” → “오퍼 받았어”로 이어가세요.
모의면접은 한 질문씩 진행하며 “끝내자” 후에 복기합니다. 회사를 여러 곳 준비하면 맥락을 분리합니다.

CareerPilot 전용 계정·API key·서버가 필요하지 않습니다. 호스트의 기존 이용 조건은 적용됩니다.
웹·음성·파일 기능은 환경에 따라 다릅니다. [경력 정보 저장/복구](docs/state-portability.md),
[개인정보 안내](docs/privacy.md), [문제 해결](docs/troubleshooting.md).
전자책 없이 독립 사용 가능하며 [주제 연결표](docs/ebook-map.yaml)로 연계합니다.

## Release status
Full V1 implementation, 1.0.0-rc.3 candidate version. Native install signoffs and actual model
evaluations determine eligibility; a candidate version label is not a release-readiness claim.
See [gate evidence](docs/GATES.md) and [native signoff checklist](docs/native-install-test.md).

## Developer verification
Python 3.12 is development-only. `python -m pip install -r requirements-dev.txt`, then
`python -m scripts.run_static_evals`, `python -m pytest -q`, `python -m scripts.package_release`.
`python -m scripts.run_model_evals --platform chatgpt` or `--platform claude` uses existing
authenticated developer CLIs; no credential is part of the product. See [eval guide](evals/README.md).
Core is canonical; adapters generated by `python -m scripts.generate_adapters`.
dist/ is generated-only. [Product specification](product/PRODUCT_DEFINITION.md),
[technical specification](product/TECHNICAL_SPEC.md), [implementation decisions](DECISIONS.md).
