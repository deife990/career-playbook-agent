# CareerPilot

**한국어로 시작하는 AI 이직 준비 도우미. 경력 정리부터 공고 분석, 지원서, 면접, 오퍼 비교까지 함께 준비합니다.**

전자책 **AI-Powered Job Search Playbook**을 실제 대화로 실행하는 도구입니다. ChatGPT 또는 Claude에 설치한 뒤 원하는 일을 한국어로 말하면 됩니다. 전자책을 읽지 않았거나 이력서가 없어도 시작할 수 있습니다. 모든 직종을 대상으로 하며, 외국계·글로벌 기업 지원과 영어 면접도 준비합니다.

> 현재 버전: **1.0.0-rc.7 — Full V1 출시 후보** · 검증일: **2026-10-05**
>
> ChatGPT·Claude 실제 웹 환경에서 전체 이직 과정과 새 채팅 복원을 시험했습니다. 공개 플러그인 디렉터리에 등록된 제품은 아니며, 아래 ZIP으로 직접 설치합니다.

## 먼저 설치 파일을 받으세요

사용하는 서비스에 맞는 **파일 하나만** 받으세요. 두 서비스의 ZIP은 서로 호환되지 않습니다.

| 사용할 서비스 | 다운로드 | 설치 위치 |
|---|---|---|
| ChatGPT | [ChatGPT 설치 ZIP](https://github.com/deife990/career-playbook-agent/releases/download/v1.0.0-rc.7/careerpilot-chatgpt-v1.0.0-rc.7.zip) | 플러그인 → 개인용 → 추가 → 플러그인 압축 파일 업로드 |
| Claude | [Claude 설치 ZIP](https://github.com/deife990/career-playbook-agent/releases/download/v1.0.0-rc.7/careerpilot-claude-v1.0.0-rc.7.zip) | 사용자 지정(Customize) → 스킬(Skills) → 스킬 업로드 |

[rc.7 다운로드 페이지](https://github.com/deife990/career-playbook-agent/releases/tag/v1.0.0-rc.7)에서 **Assets**를 펼쳐도 같은 파일을 받을 수 있습니다. `Source code (zip)`·`Source code (tar.gz)`는 개발용 소스이며 설치 파일이 아닙니다. 받은 설치 ZIP은 압축을 풀지 말고 그대로 업로드하세요.

CareerPilot 전용 계정, API key, 서버, Python 설치는 필요하지 않습니다. ChatGPT 또는 Claude의 기존 계정과 해당 기능을 사용할 수 있는 환경이 필요하며, 서비스 자체의 요금·사용량 제한은 적용됩니다. 설치 메뉴와 표시 이름은 계정·언어·조직 설정에 따라 다를 수 있습니다.

## ChatGPT에 설치하기

1. [ChatGPT](https://chatgpt.com)에 로그인합니다. 처음 설치할 때는 웹에서 진행하는 것을 권장합니다.
2. 왼쪽의 **플러그인(Plugins)**을 열고 **개인용(Personal)**을 선택합니다.
3. **추가(Add) → 플러그인 압축 파일 업로드**를 선택합니다.
4. 다운로드한 **`careerpilot-chatgpt-v1.0.0-rc.7.zip`**을 업로드합니다.
5. CareerPilot 상세 화면이 열리면 설치·활성화를 완료합니다. 이 버전에는 **12개 Skill**이 포함됩니다. 각각 따로 설치할 필요는 없습니다.
6. **채팅에서 사용해 보기**를 누르거나 새 채팅을 엽니다. 입력창에서 `@`를 입력해 CareerPilot 또는 해당 Skill을 선택합니다.
7. 아래 문장을 보냅니다.

```text
CareerPilot으로 이직 준비 시작하고 싶어. 한국어로 진행해줘.
```

현재 하는 일과 바꾸고 싶은 점을 확인하며 경력을 정리하기 시작하면 사용할 준비가 된 것입니다. ZIP을 일반 채팅에 첨부하는 것은 플러그인 설치와 다릅니다. 설치 후에는 새 채팅에서 시작하세요.

기존 CareerPilot이 있다면 해당 플러그인의 **추가 작업 → 새 버전 업로드**에서 rc.7 ZIP을 올리고 새 채팅을 시작하세요. 이미 설치된 항목에 업데이트를 적용하면 됩니다.

**메뉴가 없거나 “플러그인을 추가하지 못했습니다”가 나오면:** 파일명이 `careerpilot-chatgpt-v1.0.0-rc.7.zip`인지, GitHub 소스 ZIP이나 Claude ZIP을 선택하지 않았는지 먼저 확인하세요. 다시 받은 원본 ZIP을 사용하고 [설치 문제 해결](docs/troubleshooting.md)을 확인하세요. 회사 계정은 개인용 플러그인 사용이 제한될 수 있습니다.

[ChatGPT 상세 설치 안내](docs/install-chatgpt.md) · [공식 플러그인 안내](https://learn.chatgpt.com/docs/plugins)

위 개인용 업로드 경로는 2026-10-05 실제 시험 계정에서 확인했습니다. 모든 계정에 같은 메뉴가 제공된다는 의미는 아닙니다. 로컬·데스크톱 설치와 웹 계정의 플러그인 등록도 별도로 확인해야 합니다.

## Claude에 설치하기

1. [Claude](https://claude.ai)에 로그인합니다.
2. **사용자 지정(Customize) → 스킬(Skills)**로 이동합니다.
3. **스킬 추가 → 스킬 업로드**를 선택합니다. 화면에 따라 **`+` → Create skill → Upload a skill**로 표시됩니다.
4. **`careerpilot-claude-v1.0.0-rc.7.zip`**을 업로드하고 CareerPilot의 스위치를 켭니다. **하나의 Skill**로 전체 기능을 사용합니다.
5. 새 대화에서 아래 문장을 보냅니다.

```text
CareerPilot으로 이직 준비 시작하고 싶어. 한국어로 진행해줘.
```

스킬이 보이지 않으면 **Settings → Capabilities → Code execution and file creation** 설정을 확인하세요. 조직 계정은 관리자에게 사용자 스킬 생성·업로드 허용 여부를 확인해야 할 수 있습니다. 이는 Claude의 기능 설정이며 CareerPilot용 프로그램을 별도로 설치하는 절차는 아닙니다.

기존 Skill은 상세 화면의 교체·업로드 메뉴가 제공되면 새 ZIP으로 교체하고 새 대화에서 확인하세요. 업로드 후에도 자동으로 선택되지 않는다면 “CareerPilot 스킬을 사용해서 진행해줘”라고 명시하세요.

[Claude 상세 설치 안내](docs/install-claude.md) · [공식 스킬 설치 안내](https://support.claude.com/en/articles/12512180-use-skills-in-claude)

## 무엇부터 말하면 되나요?

현재 필요한 단계부터 시작하면 됩니다. 특별한 명령어나 프롬프트 작성법을 배울 필요는 없습니다.

| 하고 싶은 일 | 이렇게 말하세요 | 함께 만드는 결과 |
|---|---|---|
| 경력과 이직 조건 정리 | “이직 준비 시작하고 싶어.” | 경력 요약과 이직 요구사항 |
| 커리어 방향 설정 | “다음 커리어 방향을 같이 정해보자.” | 목표 역할과 준비 로드맵 |
| 지원할 회사·직무 찾기 | “내 조건에 맞는 회사와 포지션을 찾아줘.” | 목표 회사·공고 목록 |
| 특정 공고 분석 | “이 공고 어때?” + 링크 또는 공고 본문 | 회사·직무 분석과 지원 전략 |
| 지원서 준비 | “이 회사에 지원할래. 이력서부터 준비하자.” | 맞춤 이력서, 자기소개서, 지원 답변 |
| 면접 준비 | “이 회사 면접이 잡혔어.” | 라운드별 준비 자료와 짧은 면접 메모 |
| 모의면접 | “영어로 압박 모의면접 하자.” | 한 질문씩 연습하고 종료 후 개선점 확인 |
| 면접 복기 | “면접 끝났어.” | 실제 질문·답변 정리와 다음 라운드 전략 |
| 오퍼 비교 | “오퍼 받았어. 원래 조건이랑 비교해줘.” | 보상·근무 조건·불확실성을 비교한 결정 자료 |

한국어로 상황을 설명하고, 영어가 필요한 부분만 요청할 수 있습니다. 예: **“설명과 피드백은 한국어로, 면접 질문은 영어로 진행해줘.”**

### 이력서가 없어도 괜찮습니다

현재 업무와 직접 한 일을 조금씩 정리합니다. 모르는 정보는 “모름”, 확인되지 않은 성과는 “아직 확인 못 했어”라고 답하세요. 확인되지 않은 경험이나 수치를 CareerPilot이 대신 만들어 넣지 않습니다.

### 공고 하나로 깊이 분석하기

공고 링크·본문을 주고 “이 공고 어때?”라고 말하세요. 지원 환경이 읽을 수 있으면 PDF·스크린샷도 제공할 수 있습니다. 링크나 파일을 읽지 못하면 공고 본문을 붙여 넣어 주세요.

직무 요구사항, 회사·사업 맥락, 채용 배경 가설, 기대하는 후보자 모습을 먼저 분석한 뒤 내 경력 근거와 비교합니다. 기본적으로 숫자 합격률이나 적합도 점수 대신 **직접 근거 / 전환 가능한 근거 / 확인된 차이 / 미확인**을 구분합니다. 최신 웹 정보를 확인할 수 없으면 제공된 자료를 기준으로 진행하고 확인할 질문을 남깁니다.

### 모의면접 진행과 종료

“모의면접 하자”라고 요청한 뒤 한 질문씩 답하세요. 면접 중에는 칭찬이나 답변 코칭 없이 면접관 역할을 유지하며 모호한 답변에 근거를 묻습니다. **“모의면접 끝내자. 피드백 줘.”**라고 말하면 면접관 역할을 끝내고 약한 근거·이야기·답변 구조를 점검합니다.

음성 기능을 사용할 수 있으면 음성으로 연습할 수 있고, 없으면 텍스트로 진행합니다. rc.7의 실제 웹 시험은 텍스트 모의면접을 대상으로 했습니다.

### 실제 면접이 끝났다면

“면접 끝났어”라고 말하면 실제 질문, 추가 질문, 내 답변, 면접관 반응부터 수집합니다. 기억나지 않는 부분은 미확인으로 남기고, 새로 알게 된 회사 정보와 다음 라운드 전략을 정리합니다. 모의면접 내용과 실제 면접 기록을 구분합니다.

## 경력 정보 저장·복구하기

새 채팅으로 옮기거나 서비스를 바꾸기 전에 전체 경력 정보 묶음을 받아 보관하세요. 다른 채팅이 이전 내용을 자동으로 기억한다고 보장하지 않습니다.

1. 기존 대화에서 **“내 경력 정보 전체를 내보내줘. 회사별 지원·면접 기록도 포함해줘.”**라고 요청합니다.
2. 내려받은 경력 정보 ZIP을 본인이 안전하게 보관합니다. 파일을 만들 수 없는 환경에서는 제공된 전체 JSON 블록을 저장합니다.
3. 새 채팅에서 CareerPilot을 선택·활성화하고 **그 경력 정보 파일**을 첨부합니다.
4. **“이 경력 정보로 이어서 준비하자. 복원한 회사와 면접 기록부터 확인해줘.”**라고 말합니다.

여기서 첨부하는 **경력 정보 ZIP**은 설치 ZIP과 다릅니다. 여러 회사에 지원 중이면 **“A사 데이터 분석가 면접 준비를 이어가자”**처럼 회사·직무를 명시하세요.

[경력 정보 저장·복구 상세 안내](docs/state-portability.md)

## 안전하게 사용하는 원칙

- 중요한 정보는 **사용자가 알려준 사실 / 출처로 확인한 사실 / 추론 / 추천**으로 구분합니다.
- 경험, 프로젝트, 자격, 성과 수치를 만들어 넣지 않습니다. 모르는 정보와 확인된 부족함을 구분합니다.
- 서로 다른 회사의 공고·면접·오퍼 기록을 분리합니다. 회사가 불분명하면 먼저 확인합니다.
- 실제 지원, 메시지 전송, 오퍼 수락·거절은 사용자가 판단하고 실행합니다.
- 회사 기밀, 고객·동료 개인정보, 비밀번호·인증정보를 올리지 마세요. 내 역할과 공개 가능한 결과 위주로 설명하세요.

Mail·Drive 같은 외부 자료 연결은 필수가 아닙니다. 사용 환경에서 연결 기능이 제공되고 사용자가 허용한 범위에서만 활용합니다. [개인정보 안내](docs/privacy.md)

## 자주 묻는 질문

**전자책을 읽어야 하나요?** 읽지 않아도 독립적으로 사용할 수 있습니다. 전자책의 내용을 실천하고 싶을 때도 사용할 수 있습니다. [전자책 주제 연결표](docs/ebook-map.yaml)

**ChatGPT와 Claude에 모두 설치해야 하나요?** 평소 사용하는 서비스 하나에만 설치하면 됩니다. 다른 서비스로 이동할 때는 경력 정보를 내보내고 복원하세요.

**외국계 지원만 가능한가요?** 국내외 모든 직종에 적용하는 구조이며, 글로벌 기업 조사와 영어 면접 준비를 특히 지원합니다.

**합격이나 최신 채용 정보를 보장하나요?** 합격을 예측·보장하지 않습니다. 최신 정보 확인은 사용 환경의 웹 접근과 출처에 달려 있습니다. 조사 결과의 근거와 확인할 사항을 함께 살펴보세요.

**새 버전을 설치하면 내 경력도 자동으로 옮겨지나요?** 설치 파일은 도구이고, 경력 정보는 별도입니다. 업데이트 전에 정보를 내보내고 새 채팅에서 복원하는 것을 권장합니다.

[문제 해결 전체 안내](docs/troubleshooting.md) · [한 페이지 빠른 시작](docs/quick-start.md)

## 현재 버전의 검증 범위

| 검사 | rc.7 결과 |
|---|---|
| 깨끗한 저장소 복제본의 개발 테스트 | 83개 통과 |
| 실제 모델 평가 | ChatGPT 20/20, Claude 20/20 통과 |
| 실제 웹 설치·활성화와 필수 동작 | 각 플랫폼 필수 8개 항목 통과 |
| 전체 이직 과정 | W01–W09 가상 시나리오 실행 |
| 경력 정보 내보내기·새 채팅 복원 | 양쪽 모두 6개 JSON 파일 내용 동일 |
| 복원 후 특정 회사 정보만 변경 | 다른 회사 면접 기록과 공통 경력 정보 유지 |

모든 시험은 **시뮬레이션**임을 명시했습니다. 공개 디렉터리 게시, 신규 계정 생성, 실제 마이크 사용, 모든 선택 입력 형식은 시험하지 않았습니다. Claude의 이전 예시 버전 표기와 미확정 로드맵 제안 저장 범위 등 품질 메모도 공개된 검증 기록에 남겼습니다.

## 개발자를 위한 안내

일반 사용자는 이 절차가 필요하지 않습니다. 저장소의 기본 브랜치는 `main`, 현재 제품 버전은 `VERSION` 파일, 경력 정보 형식 버전은 별도로 관리합니다. 설치 파일은 GitHub Releases에서 배포하며 `dist/`는 자동 생성 결과이므로 소스 관리에 넣지 않습니다.

Python **3.12** 환경에서:

```bash
python -m pip install -r requirements-dev.txt
python -m scripts.run_static_evals
python -m pytest -q
python -m scripts.package_release
```

`core/`의 공통 원칙·워크플로·결과물 정의에서 `python -m scripts.generate_adapters`로 ChatGPT·Claude 패키지를 생성합니다. 실제 모델 평가에는 개발자의 기존 인증된 CLI를 사용하며 제품에 인증정보를 포함하지 않습니다. 설치·실제 모델 검증 기록이 현재 패키지와 일치해야 `python -m scripts.package_release --require-ready`를 통과합니다.
