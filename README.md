# CareerPilot
AI-Powered Job Search Playbook을 실행하는 이직 준비 도우미. 커리어 정리부터 지원, 면접, 오퍼 결정까지.

## Install for ChatGPT
설치 패키지와 marketplace 경로를 준비하고 있습니다. [설치 안내](docs/install-chatgpt.md).

## Install for Claude
하나의 CareerPilot Skill ZIP으로 설치합니다. [설치 안내](docs/install-claude.md).

## Start
“이직 준비 시작하고 싶어.” 또는 “이 공고 어때?”라고 말하세요.
[빠른 시작](docs/quick-start.md). CareerPilot 전용 계정, API key, 서버가 필요하지 않습니다.
