가상 서안의 정보로 진행한 실제 ChatGPT·Claude 캡처 6장을 바탕으로, 첫 사용 장면과 다시 보기 안내를 읽기용 HTML로 재구성했다. 입력창의 맞춤법 밑줄·커서가 없고 작은 글자도 선명하다. 요약·재구성임을 표시하고 실제 캡처 원본 링크를 제공한다. 첫 화면의 **첫 사용 미리 보기**로 바로 확인하거나, 이야기 속에서 설치 서비스 선택 후 이어서 볼 수 있다.

요청 입력 → 내 상황 이야기 → 바꿀 일 → 지킬 생활 → 다음 질문 → 내 차례의 6단계다. ChatGPT의 새 02 캡처는 상황 설명과 정리 뒤의 다음 질문을 보여주므로 첫 질문이라고 소개하지 않는다. Claude에서는 실제 첫 질문을 보여준다. 화면 밖 서안의 대사는 연출이며 AI의 실제 응답 문장을 새로 합성하지 않았다.

원본 이미지는 변경 없이 보관한다. 실제로 표시하는 10개 영역은 1배·2배·4배 확대본으로 따로 만들고, 화면 너비와 디스플레이 해상도에 맞춰 브라우저가 선택한다. Lanczos3 리샘플링·약한 윤곽 보정·WebP 무손실 압축을 사용하며, 글자를 생성하거나 응답 내용을 바꾸지 않는다. Claude의 사용량 알림과 가려진 이전 경력 문장은 기본 시연 영역에서 제외한다. 작은 화면에서는 사진 안을 좌우로 움직일 수 있고 읽기용 설명도 열 수 있다. 큰 안내에서 서비스·단계를 바꾸거나 원본을 열 수 있으며, 패널을 닫으면 같은 대사로 돌아온다. 자료 출처·원본 해시는 `assets/reference-ui/provenance.json`, 표시 영역·단계 설명은 `tutorial.js`, 확대본 정보는 `assets/reference-ui/upscaled/manifest.json`에 있다. [이미지 보정 기록](IMAGE_UPSCALE.md)을 참고한다.

이 폴더에서 `python3 -m http.server 8774 --bind 127.0.0.1`로 실행한다. 이전 0.7.1/8773은 보관한다. 새 주소의 저장은 이전 주소와 별개이며 이전 대본의 저장을 자동 이식하지 않는다.

`story.js`는 대본, `game.js`는 진행·저장·안내, `tutorial.js`는 실제 화면의 표시 범위·읽기용 설명, `cards.js`는 요청 모음이다. 첫 요청 카드와 설치 배포 ZIP은 유지한다. 기존 인물·소품·전체 화면 전환은 이어받고, 5.8초 자동 인트로는 새 도입으로 교체했다. 저장 스키마는 v8이다. 0.8.1은 같은 주소·대본 위치를 사용하므로 0.8 저장을 유지한다.

0.8.2에서는 설치 선택 중 서안을 반투명하게 만들던 규칙을 고쳤다. 설치 마지막 단계의 잘못 잘린 모바일 그림은 HTML 입력창으로 교체했다. 파일 받기에는 서비스별 실제 ZIP 카드를 쓰며 안내는 5단계로 통일했다. 경로도·재구성·과거 실제 자료를 구분하고, 현재 개인 ChatGPT ZIP 업로드 경로는 재촬영·확인 대상으로 남겼다. 사용자 계정에서 전체 설치를 재실행하지 않았다. 이번 6장은 첫 사용 예시이며 최신 설치 성공의 검증 자료는 아니다. 게임이 계정의 설치·대화 상태를 읽거나 AI에 실제 요청을 보내지는 않는다.

이서 메시지 앞에 알림과 읽기 여유를 두고, 순수 메시지는 큰 iPhone풍 기기 안에서 진행한다. 서안과 실제 대화를 시작하면 기존 대사창으로 복귀한다. 프롤로그는 숨겨졌던 두 번째 독백을 복원하고, 반복되는 하루와 새 업무 보류를 연결했다. `lesson-ui.js`·`lesson-ui.css`에 읽기용 화면이 있다. 저장 스키마와 대본 항목 수는 유지했다. [검토·참고 사례·재촬영 목록](../EP01_UX_REVIEW_V082.md)을 참고한다.

0.8.2 검증: 별도 브라우저 1440×1000·390×844에서 메시지 진입/복귀, 두 서비스의 설치 5단계, 첫 사용 HTML, 저장 복귀를 통과했다. 실제 이야기 흐름도 ChatGPT·Claude 각 37개 라벨을 거쳐 엔딩까지 확인했다. 도입부는 1600×1264(일반 모션), 1280×900·360×780(움직임 줄이기)에서 저장 복귀·도입 건너뛰기·화면 전환을 다시 검사했다. 기본 소스 검수도 통과했다. 새 개인 설치 경로와 실제 계정 설치 성공은 이 검증 범위에 포함되지 않는다.

기본 소스 검수: `node checks/source-check.cjs`. `checks/routes.js`는 격리된 브라우저에서 27개 선택 경로·12개 준비 카드·저장 실패 후 복귀를 검사한다. `checks/staging.js`로 실제 이야기 진행을 통해 장면을 확인한다. 검수는 사용자 플레이 탭의 저장을 바꾸지 않도록 별도 브라우저에서 수행한다. 이전 버전의 검수 결과를 이번 결과로 재사용하지 않는다.
