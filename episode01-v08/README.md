# 실행 빌드 0.10.2

「퇴사할 건데, 좋아해도 될까요?」의 프롤로그와 1화 플레이 빌드입니다.

## 실행

이 폴더에서 아래 명령을 실행한 뒤 브라우저에서 http://127.0.0.1:8774 를 여세요.

    python3 -m http.server 8774 --bind 127.0.0.1

브라우저에서 index.html을 직접 열지 말고 로컬 서버를 사용하세요. 저장 데이터는 브라우저의 로컬 저장소에 보관됩니다.

## 주요 파일

- story.js: 대본과 이야기 분기
- game.js, cards.js: 진행·저장·요청 카드
- tutorial.js, linear-tutorial.js, lesson-ui.js: 첫 사용 안내
- assets/: 게임 원화, 튜토리얼 자료, 글꼴
- downloads/: 게임 안에서 제공하는 예시 ZIP
- vendor/: Monogatari 엔진과 라이선스·출처 정보

이 빌드는 계정이나 대화 내용을 읽지 않으며 AI에 요청을 보내지 않습니다. 외부 서비스 링크는 사용자가 직접 선택할 때만 열립니다.
