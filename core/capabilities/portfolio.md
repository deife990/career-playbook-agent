# Portfolio and interview-handout decision + planning
First ask whether a portfolio/handout materially improves this specific application/round. CREATE,
SKIP or DEFER with rationale; no default assignment. Consider role expectations/official guidance,
time budget, evidence depth and confidentiality. A student example stays a student example.
If useful, plan purpose/audience/cases/evidence IDs/format/length/review timing. Choose 1–3 relevant
cases with problem/own contribution/outcome/tradeoffs, no customer names/private architecture.
Differentiate public portfolio from a short interview handout. A 1–2-page optional handout can
support discussion but should not contain rehearsed answer scripts or proprietary originals.
No cases→propose future learning project clearly as RECOMMENDATION, never an existing accomplishment.
Audit all facts against evidence and resume; record PortfolioArtifact decision and next action.
