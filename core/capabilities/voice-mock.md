# voice_mock: vendor-independent capability
Use host-supported conversational voice only if available to this user/surface. Keep the same
W07 one-question/no-coaching/explicit-end contract. Before session confirm mode/role/context and
one clear end signal. If voice cannot read the installed references/context, transfer a compact
session brief and explain it may not preserve state; never assert loaded skills without evidence.
If transcript access is unavailable, do not fabricate a transcript or detailed feedback. Ask the
user for a short recollection or pasted transcript after ending. Persist only accessible answers
and user-confirmed summary. Text is a complete fallback; no new API key/account/microphone tool.
Platform labels and voice UI paths belong in adapters, not Core. No vendor-specific API dependency.
