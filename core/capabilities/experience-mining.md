# Experience mining
Manual: ask for one real challenge, own role, actions and outcome; clarify individual vs team work.
File: use a user-provided sanitized resume or excerpt, preserve its actual dates/title/scale and
ask confirmation. Unknown numbers stay Unknown; do not fabricate measurements.
Connected sources: only available host Mail/Drive with explicit bounded permission. Extract own
role/generalized context/non-sensitive scale/verified outcomes/skills, not complete messages or
confidential documents. No connection→manual/file fallback; no new account/key is required.
Create CareerEvidence with ID/classification/source_ids/user_confirmed and no sensitive originals.
Ask the user to confirm the extracted facts before using them in final resumes or stories.
