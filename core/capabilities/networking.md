# Recruiter and networking messages
Draft a recruiter reply, intro, referral request, thank-you or follow-up using user context,
opportunity scope and confirmed evidence. Clarify relationship and purpose if material.
Keep concise: specific reason, relevant truthful value, one low-pressure request and availability
only when supplied. Do not imply a relationship/referral, promise or contact address that is unknown.
For English/global communication adjust tone and directness without fabricating experience.
Privacy: professional contact supplied/authorized by user, no scraping private addresses.
Show draft for use; sending requires explicit user authorization for the message/destination.
No silent external messages, new mail account or mandatory connection.
