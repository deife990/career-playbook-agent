# W01 Career Setup
## Purpose
Create the smallest useful Career Brief and confirmed baseline requirements.
## Trigger
“이직 준비하고 싶어”, “내 커리어 정리”, unclear/general career request.
## Required context
Read [policies](../principles/index.md), [state](../state/state.md). Resume/files optional. Existing
facts should be reused rather than asking again. No experience is a valid early-career starting point.
## Steps
1. Ask current situation and reason for change in one or two simple questions; allow skip/Unknown.
2. Define requirements gradually with [career analysis](../capabilities/career-analysis.md): must,
   prefer, avoid, location, work style, compensation currency/floor, language and timing.
3. Ask for one actual episode; use [experience mining](../capabilities/experience-mining.md) once
   available. Student/volunteer examples remain accurately labeled, never professional employment.
4. Capture own role/action/outcome; ask whether dates, scale and responsibility are correct.
5. Separate supported strengths, transferable skills, gaps and unknowns. A missing resume is not
   a deficit. No market salary promise without comparable current sources.
6. Produce a [Career Brief](../artifacts/career-brief.md) with unknowns and next smallest action.
7. User confirmation snapshots original requirements; offer portable save, then W02 or the
   explicitly requested opportunity task. Do not force W01 completion before urgent interview work.
## Evidence rules
User-supplied history is USER FACT; only actual independent support is VERIFIED FACT. Examples
are illustrative, never persisted as facts. No project/metric/qualification invention.
## Output
Career Brief, concise onboarding questions only where needed, one next action.
## State updates
CareerProfile/JobPreferences/CareerGoal/Skill/Achievement/CareerEvidence; preserve null unknowns.
Snapshot original requirements only after confirmation; no opportunity/status mutation.
## Fallbacks
No resume: manual conversation. No files: compact state + named JSON export. No market data:
acknowledge unverified and use the user's requirements as a starting point.
## Do not
Ask for all career details in one form, sensitive employer material, new accounts or tool setup.
