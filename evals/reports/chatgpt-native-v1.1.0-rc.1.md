# ChatGPT 웹 실제 설치·시뮬레이션 기록 — v1.1.0-rc.1

관찰일: 2026-10-09 · 관찰자: Codex(컴퓨터 사용) · 계정: 기존 ChatGPT Plus 계정, 웹 Chrome, 모델 표시 High
모든 대화는 **SIMULATION ONLY**로 명시했고 후보자·회사·제출은 모두 가상입니다.

## 설치

사용자 승인 후 기존 개인용 CareerPilot에 `추가 작업 → 새 버전 업로드`로
`careerpilot-chatgpt-v1.1.0-rc.1.zip`을 올렸습니다. “새 버전이 업로드되었습니다”가 표시되었고 상세 화면의
버전이 `1.1.0-rc.1`, Skill 12개로 바뀌었습니다. 추가 Skill 설치는 없었습니다.

이후 같은 rc.1 번호로 진단 문구를 고친 패키지(e1cb324, 2b8f72c)는 브라우저 자동 업로드 경로가 파일 선택 창을
열지 못해 웹에 다시 올리지 못했습니다. 아래 웹 관찰은 첫 업로드본 기준이며, 최신 패키지의 웹 재관찰은 남아 있습니다.

## 관찰 결과

| 단계 | 결과 |

| W01 경력 정리 | 사실을 USER FACT로 정리, 성과 수치 Unknown 유지, SQL을 “다른 사람 쿼리 결과 검토”로 한정 |

## 발견한 문제와 조치

1. 결과 보고가 파일 중심이었고 Recruiter Scan/HM 판정 등급, 파일 추출·페이지 수 검사 결과를 보여주지 않았다.
   상세 W05 계약을 읽지 못했다고 스스로 밝혔다. → 공통 entry guard에 W05 보고 항목과 제출본 확인 요청을 추가하고
   `screening-k-report` 모델 평가를 새로 만들었다.
2. 이력서 문장에 “query authoring and design were outside the role scope”처럼 하지 않은 일을 직접 적었다.
   사실 왜곡은 아니지만 서류에서는 불필요한 약점 노출이다. → 범위는 긍정형으로, 하지 않은 일은 갭 메모·면접 준비로 이동.
3. ChatGPT가 가상 데이터를 계정 메모리에 저장했다(“메모리 업데이트됨”). → 가상 데이터는 계정 메모리에 저장하지 않고,
   실제 정보도 사용자 동의가 있을 때만 저장하도록 entry guard와 state 계약을 수정했다.
   테스트 계정 메모리의 가상 항목은 사용자가 설정 → 개인 맞춤 설정 → 메모리에서 삭제할 수 있다.

## 판정

설치와 핵심 사실 보호(없는 경험·수치 미생성, 회사·제출본 분리)는 통과. 보고 형식과 메모리 사용은 수정 후
모델 평가로 재검증 중이며, 최신 패키지의 웹 재관찰 전까지 v1.1 native signoff는 PENDING이다.
