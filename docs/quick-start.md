# CareerPilot 빠른 시작
1. [ChatGPT](install-chatgpt.md) 또는 [Claude](install-claude.md)에 CareerPilot을 설치하고 새 대화를 시작하세요.
2. “이직 준비 시작하고 싶어.”라고 말하세요. 지금 하는 일과 바꾸고 싶은 점부터 조금씩 정리합니다.
   이력서가 없어도 시작할 수 있고 모르는 정보는 “모름”이라고 답하면 됩니다.
3. 공고가 있으면 링크·본문·PDF·스크린샷을 주고 “이 공고 어때?”라고 말하세요.
4. “여기 지원할래”, “면접 잡혔어”, “모의면접 하자”, “면접 끝났어”, “오퍼 받았어”로 이어가세요.
   지원 회사가 여러 곳이면 어느 회사의 작업인지 먼저 확인합니다.
5. 모의면접에서는 한 질문씩 답하고 “끝내자”라고 말하면 복기를 받습니다. 음성 기능이 있으면
   같은 방식으로 연습할 수 있고, 없으면 텍스트로 진행합니다.
6. 새 대화로 옮기기 전 “내 경력 정보 내보내줘”라고 말해 전체 정보 묶음을 저장하세요.
   새 대화에 다시 올리고 “이 정보로 이어서 준비하자”라고 말하세요.

전자책을 읽지 않아도 사용 가능합니다. CareerPilot 전용 계정·API key·서버 설정은 없습니다.
호스트의 기존 이용 조건은 적용됩니다. 최신 웹 정보를 확인할 수 없으면 그 한계를 알려드립니다.
회사 기밀·고객정보·비밀번호를 올리지 말고 본인의 역할과 결과를 안전하게 요약해 주세요.
