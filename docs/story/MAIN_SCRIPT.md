## 읽기와 조립 규칙

- **[장면]**은 배경·표정·화면 지시다. 대사 한 개 또는 짧은 지문 한 덩어리마다 다음으로 넘긴다. 실제 기다림·타이핑 지연은 강제하지 않는다.
- C는 감정 선택이다. 선택한 반응만 읽고 명시된 합류 장면으로 이동한다. 서로 다른 반응을 전부 연달아 재생하지 않는다.
- T02~T06은 회차별 준비 카드다. 실제 사용 / 가상 예시 / 지금은 계속의 세 경로가 있고 같은 장면으로 돌아온다. 자기보고 완료 여부는 관계·엔딩에 쓰지 않는다.
- T 카드의 예시는 **가상 예시 · 실제 AI 응답이 아님**이라고 표시한다. 예시 문서는 사용자 경력으로 보내지 않는다. 실제 요청에만 ‘요청 복사’를 붙이고 사용자가 자기 자료로 외부 대화에서 진행한다.
- 메뉴에서 S 장면을 열 때 원래 위치를 보관한다. 닫기·나중에·예시 완료 모두 원래 위치로 복귀한다. 타이틀에서 열었으면 타이틀로 돌아온다.
- 새 회차를 시작할 때 시간 경과를 명시한다. 전편 읽기와 외부 실제 준비를 모두 하루 안에 끝내는 이야기가 아니다.

## 사건·문서 연속성의 확정값

| 대상 | 고정된 사건 / 알려진 범위 |
|---|---|
| A사 | 서안이 1화 이전에 지원한 수도권 회사. 2화 오후 첫 면접, 이후 추가 전형, 5화 정식 오퍼. 6화 필수 근무 조건 조정 불가 답변 뒤 고사. 실제 회사명·공고·보상 수치 없음. |
| B사 | 3화 이서가 보낸 별개의 고연봉 공고. 수도권 상주 조건. 서안이 지원했다고 쓰지 않음. |
| 내 지원처 | 주인공의 별도 가상 지원. 3화 이후 제출, 4화 면접 초대, 5화 면접과 확인된 다음 라운드, 시간이 흐른 6화 제안 수락·마지막 근무. 직무·지역·성과·급여는 미지정. |
| 서안의 첫 제출본 | 1화 ‘파크 운영’은 문서 중 한 줄의 발췌다. 전체가 네 글자인 이력서라는 뜻은 아니다. 제출 당시 문서는 보존한다. |
| 확인된 경험 | 안내 위치를 바꾸고 변경 내용을 다음 근무자에게 공유했다. 성과 수치·혼잡 개선·단독 주도 여부는 확인 안 됨. |
| 과장된 문장 | 3화 새 초안의 ‘운영 혁신 주도’. 과장으로 지우며 과거 제출 사실로 취급하지 않음. |
| 뒤늦게 떠올린 행동 | S11에서 서안이 ‘다음 담당자에게 변경 위치를 직접 보여줬다’를 명시 확인할 때만 새 확인 기록에 추가. 실제 면접 당시 답변은 수정하지 않음. |
| 초대·면접관 | 초대의 실제 시간·방식·라운드는 외부 사용자 자료로 확인. 게임에서 채용담당자 실명·성격·합격 확률을 만들어주지 않음. |

모든 채용 진행은 허구의 줄거리다. 주인공의 합격을 실제 사용자에게 보상으로 주거나, 준비 카드 방문을 실제 지원 상태로 계산하지 않는다. A사/B사는 화면에서도 처음 등장할 때 ‘이야기 속 가상 회사’로 소개한다.

## 관계의 기억

C1~C3은 기존 1화 선택을 보존한다. C4~C12는 직후 반응과 회차 안의 한 번의 회수를 제공한다. 독립 루트·누적 호감 점수는 없다. C13에서 날짜 약속 또는 동맹 후일담을 **직접 선택**한다. 어느 엔딩도 실제 이직·플러그인 사용·이전 선택 조합으로 잠그지 않는다.

6화 이어서 읽기부터 시작해 C1~C3 기록이 없으면 각 콜백의 ‘처음 읽기’ 문장을 쓴다. 없는 선택을 추측하지 않는다. 베타에서는 장면 선택으로 모든 회차를 읽게 할 수 있으나 실제 채용 단계의 해금으로 표시하지 않는다.
