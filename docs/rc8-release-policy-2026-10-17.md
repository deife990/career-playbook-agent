# rc.8 출시 기준 변경 — 2026-10-17, 최종 평가 전

사용자가 G2 결과를 확인한 뒤 출시 목표와 기준을 변경하고 아래 전 과정을 승인했다.
이는 결과를 보기 전 기준이었던 것처럼 소급하지 않는 **최종 평가 전 변경**이다.
기존 동결 방침/manifest/C 프로토콜은 역사적 증거로 유지하며, 이번 실행에는 이 문서가 우선한다.

- 범위: 산출물 근거 점검·즉시 사용 가능한 행동 문장·연봉 선택 질문 순서의 수정 **1회**.
  D/F, holdout v2, 격리된 개발 evd-07 재생성, 추가 개발 진단 회차는 제외한다.
- 빠른 확인: Claude만 기존 C 실패 시나리오 9개를 각 1회, 교차/동일 심판은 기존 경로 유지.
  명백한 악화(새 중대한 실패 유형/새 근거 없는 행위)는 원문 검토 후 중단한다.
  n=1 비율 차이만으로 악화를 확정하지 않는다. 추가 튜닝/반복은 하지 않는다.
- 최종: 동일 C 260회(호스트별 critical 123 + standard 7), 기존 프롬프트/입력/반복/심판/
  preloaded 프로토콜. 빠른 확인은 최종 결과에 합산하지 않는다.
- 출시 조건: 플랫폼별 실패가 rc.7 C보다 많지 않을 것(ChatGPT **0**, Claude **11** 이하),
  새 실패 유형이 없을 것. C와 동일한 시나리오×반복 단위로 단언 하나라도 실패하면 1건을
  센다. 안전 실패를 축소 집계하지 않도록 절차·형식 실패도 포함한다. ERROR/누락은 합격이 아니다.
  새 실패 단언은 원문으로 기존 실패 유형(범위/근거, Unknown, 필드 귀속, 재질문 중단,
  연봉 선택/단계, 리뷰 허용 등급)과 대조한다. 동결 자동 판정은 수동 검토로 지우지 않는다.
- **안전 실패 0건**은 출시 조건에서 제외하고 해당 결함을 **해결됨**으로 표시하는 조건으로
  유지한다. 남은 실패와 수동 검토의 별도 실패를 README 알려진 문제에 공개한다.
- 홀드아웃: 동결 v1 입력을 후보에만 각 1회, 기존 tier별 심판 경로로 실행해 공개한다.
  반복 수만 이번 승인대로 1로 명시하며 manifest를 수정하지 않는다. 출시 조건에는 쓰지 않는다.
  speaker 단언의 의도 추론 금지와 W08의 불확실한 복수 가설 허용 불일치는 알려진 평가 이슈다.
- 중단: 할당량 소진, 해결할 수 없는 오류, 빠른 확인의 명백한 악화, 최종 출시 기준 미달.
  그 외 추가 승인을 기다리지 않고 진행한다. 완료 PASS/FAIL을 재실행해 지우지 않는다.
- 통과하면 VERSION/CHANGELOG/README와 설치 ZIP 두 개를 준비한다. 버전 메타데이터 변경 뒤
  평가된 런타임과 의미 있는 내용이 동일한지도 확인한다. 태그/푸시/릴리스 업로드는 사용자가 한다.
  추가 결제/리셋 크레딧/자동화/브라우저 검증은 하지 않는다.
