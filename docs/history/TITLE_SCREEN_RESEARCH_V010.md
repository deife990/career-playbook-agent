## 이번 결정
기존 펍 CG 대신 **전용 호숫가 저녁 배경 + 네 여성 인물의 투명 단체 원화**를 새로 제작한다. 추천 A안은 왼쪽 제목·세로 메뉴, 오른쪽 인물이다. 서안이 앞에 서고 이서·윤 팀장·나리가 함께 등장한다. 특정 외모가 정해지지 않은 사용자 주인공은 그리지 않는다.

K웹툰과 애니메이션 사이의 섬세한 인물 화풍, 장미색·연보라·호수의 청록·따뜻한 조명을 사용한다. 장르의 기대는 관계와 퇴근 후 일상으로 전달하고 CareerPilot 소개는 메뉴에서 이어간다. 기존 펍 장면·원화·서사·저장 데이터는 그대로 이어진다.

## 레이아웃과 인물 위계
- **A / 적용안:** 왼쪽 제목·세로 메뉴 / 오른쪽 단체 원화. 읽는 순서가 제목 → 시작 → 등장인물로 안정적이다.
- **B / 비교안:** 왼쪽 단체 원화 / 오른쪽 제목·메뉴. 첨부 레퍼런스와 같은 방향. 원화를 거울처럼 뒤집지 않고 위치만 옮긴다.
- **C / 비교안:** 인물을 낮추고 제목·풍경 여백을 넓힌다. 표정보다 공간이 먼저 읽히는 차분한 변형이다.
- **모바일 공통:** 인물을 위에, 제목과 메뉴를 아래에 둔다. 캐릭터 얼굴 위에 글자나 버튼을 올리지 않는다. 낮은 높이에서는 세로 스크롤을 허용한다.

메뉴는 저장이 있을 때만 **이어서 하기**, **처음부터 시작**, **CareerPilot 받기**, **첫 사용 미리 보기**, **환경설정** 순서다. 별도 장식 버튼은 넣지 않는다. 기본 타이틀에서는 진행 중의 기록/내 준비 상단 바를 숨기고, 시작하면 복귀시킨다. 환경설정에서 효과음을 제어할 수 있다.

네 사람이 나온다고 네 개의 공략 루트를 약속하는 화면은 아니다. 서안 중심의 1화와 주변 인물의 관계를 보여주는 앙상블이다. 바깥 장면이므로 서안은 재킷을 입고, 펍의 외투 없는 실내 설정은 유지한다.
