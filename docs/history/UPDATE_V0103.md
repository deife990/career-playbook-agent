# 0.10.3 · 팀 메시지와 서안 등장 분리

- 윤 팀장의 마지막 메시지에서 **휴대폰 내리기 →**를 누르면 휴대폰과 원격 인물 이미지가 함께 사라진다.
- 다음 화면에서는 퇴근길 배경 위에서 재킷을 두드리는 감촉·똑똑똑 효과만 표시한다. 한 번 더 진행하면 주인공의 반응, 이후 기존 페이드와 서안 등장이 이어진다.
- 알림 유지 구간을 서안의 이미지 등장 직전까지로 잡던 조건을 똑똑똑 장면 직전으로 조정했다. 메시지와 현재 사건을 동시에 표시하던 원인을 제거했다.
- 펍의 출입증 벗기 대사와 해당 이벤트 이미지 연결을 제거했다. 기존 니트 차림·편안한 착석 원화와 소매를 정리하며 긴장을 푸는 묘사로 대체한다. 게이트에서 출입증을 찍는 동작은 유지한다.
- 기존 라벨과 배열 인덱스, 저장 스키마는 유지해 기존 위치에서 이어 읽을 수 있다.

## 확인

1440×1000, 390×844에서 실제 다음 버튼으로 알림→윤 팀장 메시지→똑똑똑→주인공 반응→서안 등장 순서를 확인했다. 똑똑똑 장면에서 저장·새로고침 후 복귀해도 휴대폰과 윤 팀장이 다시 나오지 않는다. 펍 소매 정리 장면에서 출입증 원화가 나오지 않으며 기존 분기 대사로 이어진다. 자바스크립트·HTTP 오류와 가로 넘침이 없고, 원본 대사·선택지 및 배포 ZIP 검증도 통과했다.
