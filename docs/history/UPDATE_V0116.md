“집에 잘 들어갔어? 나도 도착.” 뒤에는 손 흔드는 곰, “오늘 그 얘기 들어줘서 고마워.” 뒤에는 하트를 안은 곰을 별도 이미지 메시지로 표시합니다. 게임을 위해 새로 그린 SVG 2종이며 외부 이모티콘 팩에 의존하지 않습니다. 글 말풍선 밖의 투명 이미지이고 화면 높이 600px 이하에서는 크기를 줄입니다.

기존 입력 중 표시 이후 글과 함께 등장하고 이모티콘에 짧은 크기·투명도 모션을 줍니다. 움직임 줄이기에서는 즉시 정지 이미지로 표시합니다. “그리고…”와 도착 답장 부탁, 마지막 답장 선택은 유지합니다. 기존 대사·라벨·저장 좌표를 바꾸지 않고 정확한 메시지 문장에만 이모티콘을 연결했습니다.

검증: 세 크기에서 첫 인사와 감사 이모티콘 표시, 다음 메시지 클릭, 입력 중 빠른 클릭, 정상/움직임 줄이기 표시, 저장 후 이어하기 시 중복 없이 두 개 복원, 이미지 로딩 성공, 가로 넘침 및 페이지 오류 없음. review/v0116/stickers.json 및 크기별 wave.png/thanks.png 참조. checks/source-check.cjs의 원문·선택지·배포 파일 검사 통과.
