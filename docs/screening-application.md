# 이력서·지원서 준비 — v1.1

CareerPilot 하나로 경력 근거 정리, 지원 공고에 맞춘 이력서, 지원 질문 답변, 제출 파일
검사와 면접 연결까지 진행합니다. 설명은 한국어로 받고 제출 문서는 원하는 언어로 요청하세요.

## 원하는 작업부터 말하기

| 작업 | 예시 |
|---|---|
| 전체 경력을 보관할 원본 이력서 | “내 실제 경험을 정리해서 Master 이력서를 만들자.” |
| 기존 이력서 검사 | “이 이력서를 채용담당자와 현업 관리자 관점에서 검토해줘.” |
| 공고별 맞춤 이력서 | “이 공고에 맞게 이력서를 조정해줘. 없는 경험은 넣지 마.” |
| 최종 제출물 | “검사를 마치고 제출할 DOCX와 PDF를 만들어줘.” |
| 지원 질문 | “이 회사 지원 동기 300자와 희망 연봉 입력을 같이 준비하자.” |

빠르게 점검할 때는 Quick, 일반 지원은 Standard, 중요한 지원은 Deep이라고 요청할 수
있습니다. 깊이를 줄여도 사실 확인·책임 범위·파일 검사 원칙은 유지합니다.

## 무엇을 확인하나요?

공고 요구사항을 필수·우대·책임·도메인·도구·협업 상대·경력 수준·사업 결과로 나누고,
숨은 채용 필요는 추론으로 구분합니다. 내 경험과는 **직접 일치 / 전환 가능 / 부분 일치 /
확인된 차이 / 미확인**으로 연결합니다. 공고에 있는 기술이 자동으로 내 기술이 되지 않습니다.

실제로 한 일을 재배열하고 중요한 bullet을 위로 올립니다. 숫자를 모르면 추정하지 않고
확인 가능한 주기·환경·범위·협업 맥락을 사용합니다. 도구를 사용하거나 결과를 검토한
경험과 직접 책임지고 설계·운영한 경험도 구분합니다.

그 다음 아래 질문을 따로 검토합니다.

- 채용 시스템이 텍스트와 섹션을 읽을 수 있는가?
- 채용담당자가 첫 5~10초에 목표 직무와 중요한 경험을 이해할 수 있는가?
- 현업 관리자의 추가 질문에 모든 claim을 설명할 수 있는가?
- 나만의 경험 조합과 경력 흐름이 보이는가?
- 이력서·LinkedIn·지원 답변·면접 소개가 같은 사실을 말하는가?

채용담당자 검사는 Strong / Adequate / Weak / Risk로 근거를 붙여 설명합니다.
파일 검사는 ATS-Ready / ATS-Risky / ATS-Broken 또는 NOT_CHECKED로 표시합니다.
ATS-Ready는 검사한 파일의 읽기 가능성에 대한 결과이며 합격률이나 실제 지원 사이트의
파싱 결과를 보장하지 않습니다. 회사·직무에 대한 관심 이유도 본인이 확인한 이유를 사용합니다.

## 최종 DOCX/PDF

파일 생성 기능이 있는 환경에서는 두 형식으로 만들고 PDF의 실제 텍스트 추출, 페이지 수,
이름·회사·직책·기간·bullet 누락과 순서, 한글·특수문자, 잘림, 링크와 화면 균형을 확인합니다.
검사 도구가 없으면 검사하지 못한 항목을 남기고 문서 내용과 변환 안내를 제공합니다.
파일이나 다운로드 링크를 만들지 못했는데 만들었다고 말하지 않습니다.

마지막 문장 수정은 뜻을 보존합니다. 상투적인 표현을 줄여도 성과·숫자·직급·책임 범위는
강해지지 않습니다. 잘 이해되지 않는 수정은 원문과 나란히 확인하세요.

## 제출한 버전을 보관하기

제출 후 “A사 QA Analyst에 오늘 이 PDF와 지원 답변으로 제출했어”라고 알려주세요.
실제 제출일·회사·공고·이력서 버전·bullet·summary·지원 답변·cover letter를 보존합니다.
제출 전 최종 초안을 준비한 것과 실제 제출 사실은 별도입니다.

나중에 Master를 수정해도 제출본은 바뀌지 않습니다. 정정·재제출은 새 버전을 만듭니다.
“A사 면접 준비하자”라고 말하면 실제 제출한 버전부터 확인합니다. 제출본이 없거나 여러
제출본 중 어느 것인지 불명확하면 실제 자료를 먼저 확인합니다.

새 채팅으로 옮기기 전 경력 정보 전체와 실제 제출 파일을 내보내세요. JSON 상태만
저장했다면 PDF/DOCX 바이너리까지 저장된 것은 아닙니다. 기존 V1 경력 정보는 v1.1에서
변환 없이 읽습니다. v1.1에서 새 항목을 저장한 정보는 최신 CareerPilot에서 복원하세요.
[저장 형식과 호환 범위](v1-1-state.md).

## 오퍼 전 연봉 질문

지원서 → 리크루터 스크린 → 진행 중 → 오퍼 직전 → 정식 오퍼 단계에 맞춰 준비합니다.
기본급과 총보상, 통화와 연간/월간 기준, 직무 범위를 먼저 구분합니다. 희망 금액이
정해지지 않았는데 숫자만 받는 입력란이면 임의 금액이나 0을 넣지 않고 확인할 방법을
정합니다. 현재 연봉 질문의 법적 제한은 해당 국가·지역의 최신 근거를 확인한 경우에만
설명합니다. CareerPilot은 지원서를 자동 제출하거나 협상을 대신 확정하지 않습니다.
