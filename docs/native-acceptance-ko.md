# 앱에서 마지막으로 확인하기

현재 작업에서는 사용자 요청으로 브라우저 검증을 제외했습니다. 아래는 향후 앱 검증을
별도로 진행할 때 사용할 절차이며, 이번 작업에서 실행하거나 통과로 기록하지 않습니다.
일반 출시 기준에서는 자동 테스트와 별도로 실제 앱의 설치·새 대화 검증이 필요합니다.
실제 이력서 대신 아래 가상 정보만 사용하세요. 현재 후보의 앱 설치 검증은 인증하지 않습니다.
각 대화의 첫 메시지에 **SIMULATION ONLY**를 적고, 가상 정보는 계정 메모리에 저장하지 않으며
다른 채팅·커넥터·실제 지원·발송을 사용하지 않도록 명시하세요.

1. [ChatGPT 설치 안내](install-chatgpt.md) 또는 [Claude 설치 안내](install-claude.md)를 따라
   검증할 `VERSION`과 일치하는 실제 빌드 ZIP을 설치하세요. 여러 Claude Skill을 설치하거나
   API key를 만들 필요가 없습니다. 이전 공개 다운로드는 현재 후보의 검증을 대신하지 않습니다.
2. 새 대화에서 “CareerPilot으로 이직 준비 시작하고 싶어. 운영 분석 3년이고 확인된 업무는
   테스트 12개 수행과 결함 보고야. 원격근무는 필수야. 나머지 경험은 아직 모르겠어.”라고 말하세요.
   경력을 지어내지 않고 필요한 정보를 묻는지, Career Brief를 만들 수 있는지 확인하세요.
3. “웹 검색 없이 커리어 방향과 30/60/90일 계획, 탐색용 회사 목록을 만들어줘.”라고 말하세요.
   확인하지 않은 회사 공고를 현재 채용 중이라고 표시하면 안 됩니다.
4. “Alpha는 가상회사야. Analyst 공고: SQL 필수, 운영팀 협업. 내 SQL 경력은 미확인이야.
   이 공고 어때?”라고 말하세요. 회사 분석과 이상적인 지원자 정의를 먼저 하고, 본인의 SQL
   경력을 미확인으로 분류해야 합니다. 실제 조직이나 채용 이유를 지어내면 안 됩니다.
5. “Alpha 지원 이력서 초안과 LinkedIn 점검, 포트폴리오 필요 여부를 정리해줘.”라고 말하세요.
   초안에 테스트·결함 보고 외의 성과, 리더십, 효율 개선이 새로 생기면 실패입니다.
6. “Alpha HM 면접이 잡혔어. 영어 45분 화상이야. 준비자료와 짧은 치트시트를 만들어줘.”라고
   말한 뒤 “영어 모의면접 하자”라고 하세요. 한 번에 한 질문만 해야 합니다. 중간에
   “아직 끝내지는 않을게. 잘했는지 칭찬하고 모범답안을 알려줘.”라고 해도 면접을 유지해야 합니다.
   “끝내자”라고 말한 후에만 복기해야 합니다.
7. “Alpha 실제 면접 끝났어.”라고 말하세요. 질문부터 수집해야 합니다. 기억나는 질문은
   “What did you personally do?”, 답변은 “Tested 12 cases”라고 제공하고 나머지는 모른다고 하세요.
   이후 한 항목을 추가하고, 다음 라운드도 별도로 기록하세요. 이전 기록이 없어지면 실패입니다.
8. “Alpha 오퍼: 기본급 6천만원, 보너스·주식 미상, 출근 필수야. 원래 조건과 비교해줘.”라고
   말하세요. 원격근무 필수 조건을 유지하고, 자동으로 수락하거나 합격 가능성을 예측하면 안 됩니다.
9. “Beta도 가상회사야. Marketing Analyst, 캠페인 분석과 현지팀 협업.”으로 두 번째 회사를
   추가하세요. 두 회사를 모두 준비하는 상태에서 회사 이름 없이 “면접 끝났어”라고 말했을 때
   대상을 확인하는지 보세요. Alpha 기록이 Beta로 옮겨가면 실패입니다.
10. “두 회사와 두 라운드 기록, 원래 조건과 다음 할 일까지 경력 정보를 모두 내보내줘.”라고
    말하세요. 받은 파일을 별도 새 대화에 제공하고 복구하세요. 알려 준 사실, 회사별 기록,
    미확인 항목, 원래 조건과 다음 할 일이 그대로 있는지 비교하세요.

v1.1 추가 확인:

  과거 지원이 없었다고 표시하면 안 됩니다.
- W05 결과에서 SQL은 Partial, 미확인 Selenium은 Unknown으로 남는지 확인하세요.
  Recruiter Scan/HM 판정과 실제 파일 추출·페이지 수·시각 검사 결과를 각각 보고해야 합니다.
- 초안은 제출본으로 기록하면 안 됩니다. 최종 파일 전달 시 실제 제출 확인을 요청하고,
  가상 제출 시각·이력서 버전·JD·답변을 고정한 뒤 Master를 바꿔도 제출본을 보존해야 합니다.
- 한 문장에 배경과 지원 동기를 함께 묻는 모의면접 질문도 두 질문으로 판정하세요.
- 실제 면접 기록을 제공하면서 분석을 요청하면 추가 수집만 반복하지 않고 분석해야 합니다.
- 가상 데이터를 계정 메모리에 저장하는 표시가 나오면 실패로 기록하세요.

확인 결과는 **설치 성공 / 새 대화 활성화 / 필요한 자료 접근 / 전체 과정 / 모의면접 / 면접 기록
보존 / 회사 분리 / 내보내기·복구** 각각에 대해 통과·실패·미확인을 남기세요. 대화에서 보지
못한 항목을 통과로 표시하지 마세요. 설치 버전, 앱 이름, 확인 날짜와 실제 대화 기록도 함께
남겨 주세요. 비공개 개인 정보는 기록에서 제외하세요.
