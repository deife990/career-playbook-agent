# Copilot Bridge 빠른 시작

1. 채용공고를 주고 “이 공고에 지원할 경험을 점검해줘”라고 말하세요.
2. CareerPilot이 기존 자료를 먼저 확인하고 부족한 근거를 보여줍니다. 충분하면 검색을 생략합니다.
3. “업무기록에서 더 찾아보자. 회사 Copilot을 사용할 수 있어”라고 말하세요.
4. 찾을 경험과 기간·자료 범위를 정합니다. CareerPilot이 그 조건에 맞는 복사할 검색 요청을 만듭니다.
5. 회사에서 승인된 Copilot에 요청을 실행합니다. CareerPilot이 회사 메일을 직접 읽지 않습니다.
6. 비밀번호·고객/직원 정보·내부 주소·계약조건·가격·보안 설계·미공개 정보를 제거하거나 일반화합니다.
   “Sensitive Information Removed: Yes” 표시만 믿지 말고 실제 요약을 읽어보세요.
7. [Evidence Exchange 형식](../templates/artifacts/evidence-exchange.md)의 요약만 CareerPilot에 붙여넣습니다.
8. 직접 수행한 행동과 공유 가능한 범위가 정확한지 확인한 뒤 이력서·스토리에 반영합니다.

한 번에 공고에서 중요한 부족 항목 1–3개를 찾습니다. “메일에서 모든 경력을 찾아줘” 대신
예를 들어 설치 일정 조율이 부족하다면 그 기간의 일정 변경·현장 방문·작업 범위·완료 확인
자료를 대상으로 합니다. 날짜나 범위를 모르면 먼저 하나만 정하고, 전체 메일을 조사하지 않습니다.

첫 결과가 유망해도 본인 행동이 불명확하면 같은 사건을 좁혀 다시 찾습니다. 충분한 근거가
확보되거나 새 자료가 없으면 멈춥니다. 자료가 없다는 이유만으로 경험이 없다고 단정하지 않습니다.

회사 Copilot이 없다면 회사에서 승인된 다른 AI, 직접 제공한 안전한 파일, 기억을 떠올리는
구체적 질문으로 진행합니다. 추가 계정·API key·Work IQ·회사 계정 연결은 필요하지 않습니다.
회사 정책에 맞는 요약만 전송하세요. 원문 메일이나 회사 내부 링크 전체를 붙이지 않습니다.
