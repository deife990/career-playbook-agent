## 실행 도구 준비 (승인 후)

기존 CLI는 `evals/scenarios`와 기존 tier policy에 고정돼 있어 변형을 바로 선택할 수 없다.
이를 고치면 C suite 지문이 바뀐다. 대신 새 `scripts/run_variant_evals.py`가 기존 frozen
`run_case()`의 모델 호출/심판/체크포인트 구현을 재사용하도록 한다. 원래 하네스·평가 프롬프트는
수정하지 않는다. 새 실행기 자체는 새 execution lock에 해시로 묶고 두 평가군을 분리한다.
개발 모드의 holdout 경로/ID 거부, 입력 해시 불일치 거부, FAIL 재개 거부, 올바른 심판 경로,
오류 때 완료 subject 재사용을 모의 도구 테스트로 검증한다. 테스트에서는 실제 모델을 부르지 않는다.
