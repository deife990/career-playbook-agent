# 문제가 생겼을 때
- 설치가 안 보임: 해당 surface/워크스페이스의 marketplace·사용자 Skill 허용 여부 확인.
- ZIP 오류: Claude에는 careerpilot 폴더가 맨 위에 있고 SKILL.md가 포함된 ZIP 사용.
- 엉뚱한 회사 분석: 작업을 멈추고 회사/직무를 선택하세요. 이전 기록을 덮어쓰지 말고 분리 복구.
- 정보를 기억 못 함: 마지막 전체 경력 정보 묶음을 다시 제공하세요. 채팅 기억은 보장되지 않습니다.
- 링크/파일 못 읽음: JD 본문이나 읽을 수 있는 자료를 제공하세요. 확인하지 않은 정보는 Unknown.
- 면접 중 피드백이 나옴: 해당 시뮬레이션은 계약 위반입니다. 종료 후 기록을 보존하고 보고하세요.
- 원치 않는 추측: 해당 문장의 근거/분류를 확인하고 미확인 정보를 삭제하거나 Unknown으로 수정.
- 파일 복구 충돌: 양쪽 파일을 보관하고 최신 사실을 확인하세요. 오래된 복기로 새 기록을 덮지 마세요.
버그 보고에는 합성/익명화된 예시, 사용 환경, 단계, 예상/실제 결과를 포함하고 민감한 원문은 빼세요.
