# CareerPilot 문제 해결

현재 권장 버전은 **1.0.0-rc.7**입니다. [다운로드 페이지](https://github.com/deife990/career-playbook-agent/releases/tag/v1.0.0-rc.7)의 Assets에서 서비스에 맞는 설치 ZIP을 받으세요.

## “플러그인을 추가하지 못했습니다. 다시 시도하세요.”

1. ChatGPT에는 `careerpilot-chatgpt-v1.0.0-rc.7.zip`을 선택했는지 확인하세요.
2. `Source code (zip)`, Claude 설치 ZIP, 경력 정보 ZIP을 선택했다면 올바른 설치 파일을 다시 받으세요.
3. 압축을 풀거나 내용물을 다시 압축하지 말고 내려받은 원본 ZIP을 사용하세요.
4. 일반 채팅 첨부가 아니라 **플러그인 → 개인용 → 추가 → 플러그인 압축 파일 업로드**에서 진행하세요.
5. 이미 설치돼 있다면 해당 CareerPilot의 **추가 작업 → 새 버전 업로드**를 사용하세요.
6. 올바른 원본 ZIP도 실패하면 파일명, 발생 시각, 브라우저, 개인/조직 계정 여부와 오류 문구를 기록해 문의하세요. 일반적인 오류 문구만으로 원인을 확정할 수는 없습니다.

rc.7 원본 ZIP은 실제 ChatGPT 계정에서 수락·활성화를 확인했습니다. 모든 계정의 기능 제공이나 조직 정책을 보장하는 결과는 아닙니다. [시험 기록](../evals/reports/chatgpt-native-e2e-1.0.0-rc.7.md)

## 설치 메뉴가 보이지 않습니다

ChatGPT의 개인용 플러그인 또는 Claude의 사용자 스킬 기능이 계정에 제공되는지 확인하세요. 조직 계정은 관리자에게 업로드·설치 허용 여부를 문의하세요.

Claude는 **Settings → Capabilities → Code execution and file creation** 설정을 확인하세요. 조직 계정은 관리자가 Skills와 사용자 스킬 생성을 허용해야 할 수 있습니다. [공식 안내](https://support.claude.com/en/articles/12512180-use-skills-in-claude)

메뉴가 없는 환경에서 ZIP을 채팅에 올리는 것은 설치를 대신하지 않습니다. 사용 가능한 웹·데스크톱 환경과 조직 정책을 확인하세요.

## 업로드했는데 CareerPilot이 작동하지 않습니다

설치·활성화 상태를 확인한 다음 새 대화에서 시작하세요. ChatGPT에서는 `@`로 CareerPilot을 선택하고, Claude에서는 Skill의 스위치를 켜세요. “CareerPilot을 사용해서 한국어로 이직 준비를 시작해줘”라고 명시해 보세요. 로컬 설치가 웹 계정에도 자동 등록된다고 가정하지 마세요.

## Claude ZIP 형식 오류가 납니다

Claude용 설치 ZIP 하나를 받으세요. ZIP의 최상위에 `careerpilot/` 폴더가 있고 그 안에 `SKILL.md`가 포함된 원본입니다. 여러 스킬을 각각 설치할 필요가 없습니다. [설치 안내](install-claude.md)

## 이전 대화의 내용을 기억하지 못합니다

마지막 전체 경력 정보 묶음을 새 채팅에 첨부하고 “이 경력 정보로 복원해줘”라고 요청하세요. 요약만으로는 세부 면접 기록이 빠질 수 있습니다. 설치 ZIP과 경력 정보 ZIP을 구분하세요. [저장·복구 안내](state-portability.md)

## 링크나 PDF·이미지를 읽지 못합니다

공고 본문을 붙여 넣거나 읽을 수 있는 자료를 제공하세요. 최신 회사 정보에 접근하지 못하면 제공된 자료와 확인할 질문을 기준으로 진행합니다. 읽지 못한 내용을 확인한 사실로 취급하지 마세요.

## 다른 회사의 정보가 섞였습니다

작업을 멈추고 회사·직무를 명시하세요. “A사 기록과 B사 기록을 분리하고 원래 기록을 보존해줘”라고 요청하세요. 덮어쓰기 전에 전체 경력 정보를 보관하고 잘못 연결된 내용을 확인하세요.

## 모의면접 중 코칭이 나옵니다

“면접관 역할을 유지하고 한 질문씩 진행해줘. 피드백은 내가 종료한 뒤에 줘”라고 정정하세요. 중간 칭찬·코칭은 제품의 모의면접 규칙 위반이며, 반복되면 익명화한 재현 예시로 보고해 주세요. 종료하려면 “모의면접 끝내자. 피드백 줘”라고 말하세요.

## 사실이 아닌 경험이나 수치가 들어갔습니다

해당 문장의 근거를 확인하고 “이 경험/수치는 확인하지 않았어. 미확인으로 수정하고 관련 이력서와 이야기도 점검해줘”라고 요청하세요. 실제 확인한 경험만 사용하세요.

## 경력 정보 복원에서 충돌이 납니다

두 파일을 모두 보관하고 어느 기록이 최신인지 확인하세요. 오래된 복기로 새 면접 기록을 덮어쓰지 마세요. CareerPilot에 빠진 파일·회사·면접 기록을 먼저 확인하게 하세요.

## 오류를 보고할 때

[GitHub Issues](https://github.com/deife990/career-playbook-agent/issues)에 버전, 사용 서비스, 재현 단계, 기대한 결과와 실제 결과를 남겨 주세요. 화면·예시를 첨부할 때는 실제 이력서, 경력 정보 전체 ZIP, 회사 기밀, 연락처, 비밀번호·인증정보를 제외하고 **가상 또는 익명화한 예시**를 사용하세요.
