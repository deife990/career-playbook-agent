# 경력 정보 저장과 복구
가능하면 현재 대화나 프로젝트의 파일을 사용합니다. 다른 채팅에서도 기억된다고 보장하지 않습니다.
“내 경력 정보 내보내줘”라고 하면 manifest.json, career-profile.json, preferences.json,
story-bank.json, applications/<공고 ID>.json을 제공합니다. 민감한 내용을 검토하고 안전하게 보관하세요.
파일을 만들 수 없는 환경에서는 같은 이름의 JSON 블록을 저장하세요. 요약만 저장하면 세부 면접
기록을 잃을 수 있으므로 전체 정보 묶음을 받으세요. CareerPilot 전용 프로그램은 필요하지 않습니다.
새 대화에서 “이 경력 정보로 이어서 준비하자”와 함께 파일을 제공하세요. 복구한 회사와 면접 기록을
확인한 후 진행합니다. 파일이 빠졌거나 버전/정보가 충돌하면 기존 기록을 보존하고 확인을 요청합니다.
회사가 여러 개면 어느 회사의 작업인지 먼저 선택합니다. 다른 회사의 분석을 섞지 않습니다.
